# frontend — 教师端页面

**负责方向：前端 / UI**

## 现在就可以开始

不需要等硬件，也不需要等 backend。用 Mock Data 先把页面做起来（任务书 前端 第 1 节）。

## 页面至少显示

- 设备在线数量
- ✓ 理解 / ? 不确定 / × 未理解 的人数与比例
- 当前人数
- `Start Feedback` / `End Feedback` 按钮

设计上要想清楚（任务书第 3 节）：字体够不够大？教室一体机远距离能否看清？投票过程中是否立刻展示结果？Session 结束后怎么显示？第一阶段优先「清楚 + 好用」，不追求好看。

## 数据格式

先用 [../docs/protocol.md](../docs/protocol.md) 第 4 节的 Mock 格式；正式格式等接口对接时冻结。

## 现状

目录刚建，**框架和语言自选**（任务书明确允许）。定了之后请在这里补上启动方式。
