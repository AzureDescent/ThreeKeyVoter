## 一、尺寸采集清单（等实物到手逐项填）

| 对象 | 待测项 | 来源 | 状态 |
| --- | --- | --- | --- |
| ESP32-C3 SuperMini | 长 × 宽 × 厚、USB 口中心高度与宽度 | 我实测（已到我手上） | ⬜ |
| 按键 | 键帽直径或边长、高度、面板开孔、脚距 | 李明轩采购后 | ⬜ |
| LED | 直径、是否需要导光柱 | 李明轩采购后 | ⬜ |
| USB-C 线插头 | 插头外壳宽度（决定开孔大小） | 我实测 | ⬜ |
| 电池（若需要） | 型号、尺寸、充电口位置 | 队长拍板 | ⬜ |

参考值（**未实测，仅用于早期估算**）：ESP32-C3 SuperMini 常见规格约 22.5 × 18 mm；USB-C 插头外壳宽约 12 mm，开孔留 13 × 4 mm 比较稳。

## 二、设计约束

| 约束 | 说明 |
| --- | --- |
| ESP32 固定 | 不能靠挤压，要有明确限位或螺丝柱 |
| 按键安装 | 面板开孔对准按键，且按下时不被外壳卡住 |
| USB-C 开孔 | 网关必须能插拔线；壁厚不能挡住插头根部 |
| 可拆装 | 优先螺丝（M3 自攻或热熔铜螺母），卡扣次之 |
| 人机操作 | 学生端三键间距适配手指，按键中心距 ≥ 20 mm（**待实测**） |
| 后期空间 | 预留 PCB / 电池净空约 3 mm，但本期不做结构 |

## 三、冻结条件（全部满足才能定稿）

1. 按键、LED 实物到手并实测
2. 网关板实物到手并实测
3. 供电 / 电池方案确定
4. 与队长确认外壳数量与用途（演示 1 套 or 每人一套）

## 四、工艺（FDM 打印）

| 项 | 建议值 |
| --- | --- |
| 壁厚 | 1.6–2.0 mm（0.4 mm 喷嘴 × 4–5 线宽） |
| 装配间隙 | 0.2–0.3 mm |
| 固定 | M3 自攻 / 热熔铜螺母 |
| 摆放 | 开孔朝上，避免支撑落在配合面 |
